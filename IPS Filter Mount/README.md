# IPS Filter/Strainer mount
Mounting the IPS filter to a 2" vertical pipe. Allows for strainer to be cleaned without removing it from the mount.

<img src="images/filter mount.jpg">


Print Settings
  * Filament recommendation PETG, ASA, ABS.
  * No need for supports, just slow down head for overhangs.
  

Other Parts needed.

* 4x M2.5 Heat Sets
* 4x M2.5 x ... Screws
* 2x M3 Heat Sets
* 2x M3 x ... Screws
* Use clamps from the kit.
